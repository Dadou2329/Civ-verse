# Mask Civilization — scenario → implementation

This document maps the requirements of [`MASK_CIVILIZATION_SCENARIO.md`](MASK_CIVILIZATION_SCENARIO.md)
(« Les Cent Visages ») to the content and code of the pack `civilizations/mask`, the automated
test that exercises each one, and an honest status. The campaign is built one finished chapter at
a time (scenario §11.4); this file grows with it. Chapters that are not listed are not written.

Section numbers (§) are those of the scenario. French texts are quoted as they appear in the
locale table (typographic apostrophes, no-break spaces: see [`../LOCALIZATION.md`](../LOCALIZATION.md)).

## How to read the tables

**Paths** are relative to `civilizations/mask/`. Content ids are those of the JSON files: entity
ids of `content/scenes/rives.scene.json`, dialogue nodes as `dialogue/node`, quest, stage and
objective ids as `quest/stage/objective`, cinematic ids, logic rule ids
(`content/logic/prologue.logic.json`), localization keys. The scene and the cinematics were
generated by the seed scripts (`seed/*.ts`, `npm run civ -- seed mask`), which remain the readable
description of the layout; the JSON files are the runtime source and are edited in the Studio.

**Verified by.** Test cases of `tests/mask.prologue.test.ts` (headless: A* at the player's size,
the game's interaction pipeline, mouse buttons through the equipment system, jumps with the
player's own physics, dialogues answered, cinematics skipped, save and reload).

| Label | Test name |
| --- | --- |
| MP1 | « can be played from the room to Juno’s offer » |
| MP2 | « if the player is too slow, Juno holds the wagon back and the player tries again » |
| MP3 | « the stairs are walkable without jumping, and the key is never forgotten for good » |
| MP4 | « without the Cendre mask there is no Braise, and the plaque stays » |
| MP5 | « Nora’s scrap errand: four pieces on the quay for two pepper galettes » |
| MP6 | « the run of the wagon, the lever and the jammed brake survive a save and a reload » |

« Visual » means checked on screenshots of the running game (Chromium, software rendering), not
by an automated test.

**Status.** *Implemented*: done as specified. *Partial*: done with a stated gap. *Not done*.

### 3.8 Gaps of Chapter I

- The access to the Toits du Fil belongs to Chapter II, which is not built: the chapter ends with
  an in-game notice that the next chapter is not available yet.
- The district’s congratulations are in the neighbours’ dialogues (they change with the number of
  proofs), not spontaneous lines when the hero walks by.
- In I03 the hero holds the split mask on the test bench; he never puts it on.
- No recorded voices: French subtitles only.
- Engine limitation found and left as it is: a hidden `core.particles` entity keeps emitting.
  Fixing it would change what Memory shows today (its footstep motes are meant to appear only once
  a shard is anchored) and Memory is frozen. The Mask rain uses its own visual, which starts and
  stops.
